## Deployment

The 2026-07-28 stateless core changes the deployment posture (see
`docs/plans/2026-07-28-release-readiness-review.md` for history; this section is forward-looking):

**Lambda (primary serverless target — `turul-mcp-aws-lambda`)**
- Stateless requests need no session storage, no DynamoDB session table, and no sticky
  routing: every POST is self-contained (`_meta` carries version/identity/capabilities).
- `subscriptions/listen` is a long-lived POST SSE response — on Lambda this is bounded by
  the invocation timeout and API Gateway's 29s idle limit; deployments needing long-lived
  subscriptions should route `/mcp` listen traffic to an EC2/container tier or use
  Lambda response streaming with reconnect-on-close clients (stream state is request-scoped
  by design: clients re-issue `subscriptions/listen` after a drop).
- OAuth: `turul-mcp-oauth` validates bearer JWTs in-process (RFC 9728 PRM + RFC 9207 iss);
  API Gateway authorizers remain supported via `x-authorizer-*` extraction.
- Task support (2025 lane / future SEP-2663 extension crate) still requires
  `.with_task_storage()` with a durable backend (DynamoDB).

**EC2 / containers (long-lived servers)**
- Same binary serves both: default build = 2026 stateless; `--no-default-features
  --features protocol-2025-11-25` = stateful 2025 line (single-spec per build, ADR-029).
- `subscriptions/listen` streams are held in-process; scale-out needs either sticky routing
  for listen connections or acceptance of re-subscribe-on-rebalance (spec-sanctioned).
- Origin validation / DNS-rebinding protection is ON by default (`OriginPolicy::SameOriginOrLoopback`,
  ADR-031); cross-origin browser deployments must configure `AllowList`, and deployments that
  enforce origin upstream (API Gateway / ALB) may set `Disabled`.

**Version negotiation in mixed fleets**
- The bilingual client (`turul-mcp-client`, ADR-030) probes `server/discover` and falls back
  to 2025 `initialize` on `-32601`/`-32004`, so rolling a fleet from 2025-11-25 to
  2026-07-28 does not require client lockstep.
